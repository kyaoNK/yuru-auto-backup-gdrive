# yuru-auto-backup-gdrive

**Premiere Pro のプロジェクトを、毎日自動で Google Drive 用フォルダにコピーする Windows アプリです。**

## まず知っておくこと

- 保存するのは **`.prproj` だけ**。動画・音声などの素材は対象外です。
- バックアップは毎回上書き。**元ファイルの更新から2ヶ月経つと、条件に合うバックアップを自動削除**します。
- 元ファイルは消しませんが、**バックアップの削除は Google Drive にも反映**されます。長期保存するものは別の場所にも残してください。

## 使い始めるまでの3ステップ

### 1. インストール

Windows 11（x64）で、**パソコン版 Google ドライブ**を設定しておきます。

[ダウンロードページ](https://github.com/kyaoNK/yuru-auto-backup-gdrive/releases)の **Assets** から、`-setup.exe` で終わるファイルを入れてください。他のファイルは通常不要です。

※ インストーラーは未署名です。警告が出たら、配布元とリリースの説明を確認してください。

### 2. 「設定」で選んで保存

| 項目 | 選ぶもの |
| --- | --- |
| **監視元フォルダ** | 元のプロジェクトが入っているフォルダ |
| **出力先フォルダ** | Google Drive と同期する、バックアップ専用フォルダ |
| **実行時刻** | 毎日コピーしたい時刻 |

毎日使うなら **「Windows ログオン時に自動起動」** をオンにして、**「保存」** を押します。元と出力先は別の場所にしてください。

### 3. 「今すぐ実行」で確認

**ダッシュボード →「削除予定を確認」→ 内容を確認 →「今すぐ実行」**

コピー先に `元の名前_Latest.prproj` ができればコピー成功です。Google Drive へのアップロード完了は、パソコン版 Google ドライブで確認してください。

※ 実行時には期限切れバックアップの削除も行います。起動・設定反映後に自動実行される場合もあるので、最初はテスト用フォルダで試すと安心です。

## コピーされない？ まずフォルダ名を確認

**「数字6桁＋半角の `(`」で始まるフォルダの中**にある `.prproj` が対象です。

```text
PremiereProjects ←「監視元」に選ぶ
└─ 261001(1)_旅行動画
   └─ 旅行動画.prproj → コピー対象
```

`Auto-Save` 内、除外設定に当たるもの、更新から2ヶ月経ったものはコピーしません。

**別フォルダでも、同じファイル名は使わないでください。** コピー先で上書きされます。

## 普段は画面を閉じてOK

**× で閉じても、裏で動き続けます。** 完全に止めるには、時計の近くのアプリアイコンを右クリックして **「終了」** を選びます。終了中は自動バックアップされません。

---

以下は、必要になったときだけ読んでください。

<details>
<summary><strong>コピーできない・エラーが出る</strong></summary>

- **コピー0件**：上のフォルダ名条件、`.prproj` か、更新から2ヶ月以内か、除外設定を確認します。
- **Google Drive が見つからない**：パソコン版 Google ドライブを起動し、エクスプローラーで同期フォルダを開けるか確認します。「Google Drive を検出」で見つからなくても「選択…」で選べます。
- **なかなか終わらない**：Google Drive の準備を最大5分待つ場合があります。
- **編集中のファイルで失敗**：保存を終え、必要ならプロジェクトを閉じてから再実行します。
- **詳しい原因を知りたい**：「ログ」を開きます。保存に失敗した場合は、新しい設定が反映されているかも確認してください。

</details>

<details>
<summary><strong>2ヶ月の削除ルール・元ファイルを移動した場合</strong></summary>

**元が残っている場合**：最後に更新した日時から暦の2ヶ月で、条件を満たすバックアップを定時／手動実行時に削除します。バックアップ作成日からではありません。例えば7月31日更新なら9月30日の同じ時刻が期限です。期間は変更できません。再編集するとコピー対象に戻ります。

削除前に、アプリの管理記録とバックアップの内容を照合します。未管理・外部変更・除外されたものなどは保護します。「削除予定を確認」を押すだけでは削除しませんが、定時の自動削除を止める機能ではありません。

**元が見つからない場合（v0.3.0 から）**：自動では削除しません。

正常な実行で初めて不在を確認してから2ヶ月保留し、その後も**1件ずつ確認・同意した場合だけ削除**します。復帰・移動の可能性があるものや、安全を確認できないものは保護します。旧版の管理記録は、期限内の再コピーで新形式になるまで確認削除の対象にしません。

**移動先や改名後のファイルを見つけられないことがあります。最後のコピーを失わないよう、削除前に別のコピーを確認してください。**

</details>

<details>
<summary><strong>除外・設定ファイル・更新方法</strong></summary>

- **除外フォルダ（パス指定）**：選んだフォルダの中身をコピー対象から外します。
- **除外フォルダ名（パターン）**：`Cache` などの名前を指定します。大文字小文字は区別しませんが、`MyCache` のような別名には一致しません。`*` は使いません。
- **設定とログ**：「設定」→「設定フォルダを開く」から確認できます。通常は手で編集する必要はありません。
- **管理用ファイル**：出力先の `.yuru-backup-manifest.json` は、安全な削除判定に必要です。編集・削除しないでください。
- **更新するとき**：トレイからアプリを終了 → 設定と重要なバックアップを別の場所へ退避 → リリースの注意事項を読んで新しいインストーラーを実行します。
- **SHA256SUMS.txt**：配布ファイルの破損・改変を調べるための一覧です。インストールには不要です。

</details>

<details>
<summary><strong>開発者向け：ビルド・テスト</strong></summary>

Rust、Node.js / npm、Tauri 用の Windows ビルド環境が必要です。リポジトリのルートで実行します。

```powershell
npm ci
npm run tauri dev    # 開発用に起動
npm run tauri build  # インストーラー生成

npm run check
npm run test:unit
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
```

生成先：`src-tauri/target/release/bundle/`

画面テストは別途 Playwright と Chrome を用意して `npm run test:ui` を実行します。外部の Playwright は `PLAYWRIGHT_MODULE` に `index.mjs` の file URL を指定できます。画面テストは実データを使いませんが、**ネイティブアプリの起動時は既存設定でバックアップが始まる場合があります**。

詳しい仕様は [DESIGN.md](./DESIGN.md)、検証結果・未検証事項は [AUDIT.md](./AUDIT.md) を参照してください。

</details>
