# yuru-auto-backup-gdrive

Premiere Pro のプロジェクトファイル (`.prproj`) を、毎日 1 回の定時ジョブで Google Drive 同期フォルダにコピーする Windows 向けデスクトップアプリ。実際のクラウドアップロードは Google Drive for desktop に任せる、軽量な常駐型ツールです。

既存の PowerShell スクリプト運用（メモ帳でパス書き換え → 右クリック実行）を、設定 GUI と常駐スケジューラに置き換えます。

## できること

- 監視元フォルダを再帰スキャンし、`.prproj` を Google Drive 同期フォルダに `<元の名前>_Latest.prproj` でコピー（平置き、上書き）
- 毎日 1 回の定時実行（既定 09:00、UI で変更可）
- 元ファイルの最終更新から暦の2ヶ月でバックアップ対象外にし、管理済みの対応バックアップを削除（元ファイルは残し、再編集時は再開）
- PC がオフ／スリープで定時を逃した場合、次回起動時に取りこぼしを実行
- Google Drive for desktop が起動しきっていない場合、出力先が見えるまで最大 5 分ポーリング
- システムトレイ常駐（左クリックで設定画面、メニューから「今すぐ実行」「終了」）
- Windows ログオン時に自動起動（ON/OFF 可）
- ログ画面でレベル別（情報 / 警告 / エラー）にフィルタ表示

## バックアップの対象条件

以下を**すべて**満たすファイルだけがコピーされます。

- 拡張子が `.prproj`
- 祖先フォルダのどこかが `^\d{6}\(` にマッチ（例: `250304(3)_クイズ`）
- パスのどこにも `Auto-Save` を含まない
- 設定で指定した「除外フォルダ（パス）」のサブツリー外
- 設定で指定した「除外フォルダ名（パターン）」に祖先名が一致しない（大文字小文字区別なし）

最初の 3 つはハードコード固定、後ろ 2 つは UI から自由に編集できます。

### 2ヶ月の保持期限

定時／手動実行時に元ファイルの最終更新日時を確認し、暦の2ヶ月経過後はコピーせず、このアプリが管理している対応バックアップだけ削除します（月末は到達月の末日に丸めます）。元ファイルは削除しません。再編集されればバックアップを再開します。期間は2ヶ月固定です。

削除時は管理記録のサイズ・更新日時・SHA-256 を照合します。ハッシュのない旧管理記録は削除に使わず、期限内の再コピーで更新します。編集中で安全に読めない元ファイルは、その回のコピーをエラーにして以前のバックアップを残します。

**Google Drive 側にも削除が同期されます。** 出力先の `.yuru-backup-manifest.json` にコピー成功後の管理情報を保存します。安全のため、導入前の未管理バックアップ、外部変更されたもの、元ファイルが見つからない／除外されたものは削除しません。既存ファイルは期限内のコピー成功後に管理対象になります。管理ファイルを削除すると自動削除の対象を確認できなくなります。期限切れ・削除・保護したファイルはログ画面で確認できます。

## インストール

### ビルド済みバイナリ

リリースページから `.msi` または `.exe` を取得してインストールしてください（※ リリースは追って公開）。

### ソースからビルド

必要なツール:

- [Rust](https://www.rust-lang.org/tools/install) (1.85+)
- [Node.js](https://nodejs.org/) (20+)

```bash
git clone https://github.com/kyaoNK/yuru-auto-backup-gdrive.git
cd yuru-auto-backup-gdrive
npm install
npm run tauri build
```

ビルド後の MSI/EXE は `src-tauri/target/release/bundle/` 配下に生成されます。

### 設定とログの保存先

インストーラー版は、アップデートで消えないように `%USERPROFILE%\yuru-auto-backup-gdrive\` に `config.json` と `logs/backup.log` を置きます。手動配置のポータブル版は、実行ファイルと同じディレクトリの `data/` を使います。

## 使い方

### 1. 初回起動

アプリを起動するとダッシュボードが開きます。最初は監視元・出力先が未設定なので「設定」タブから設定してください。

### 2. 設定

**監視元フォルダ**: Premiere Pro のプロジェクトを置いているフォルダ（例: `D:\PremiereProjects`）。

**出力先フォルダ**: Google Drive 同期配下の任意のフォルダ。「Google Drive を検出」ボタンを押すと、レジストリ／ドライブレター／慣習パスを総当たりで検出し、候補一覧を表示します。候補をクリックするとそのルートを起点にフォルダ選択ダイアログが開きます。検出に失敗した場合は「選択…」ボタンから手動で選んでください。

**実行時刻**: HH:MM 形式（既定 09:00）。

**自動起動**: Windows ログオン時に常駐させる場合は ON。

**除外フォルダ（パス指定）**: 監視元の中で、特定のサブフォルダ配下を丸ごと除外したいときに追加。サブツリー全体が除外されます。

**除外フォルダ名（パターン）**: `Cache`, `Proxy`, `Render` のように、フォルダ名で除外したいときに追加（大文字小文字区別なし）。祖先のどこかにこの名前のフォルダがあれば、そのファイルは対象外になります。

最後に「保存」を押すと、設定がディスクに永続化され、スケジューラが新しい設定で再武装されます。

自動起動の変更に失敗した場合は設定を保存しません。設定保存に失敗した場合は OS の自動起動状態の復元を試みます。保存後のスケジュール反映や復元に失敗した場合は、画面に対処方法を表示します。

### 3. ダッシュボード

- 次回実行時刻、最終実行時刻、最後のサマリ（コピー件数 / エラー件数）が表示されます。
- 「今すぐ実行」ボタンで定時を待たずに手動実行できます。
- 「削除予定を確認」で、保存済み設定に基づく削除予定一覧と削除しないバックアップを確認できます。確認だけではコピー・削除・管理情報更新をしません。出力先が利用できない場合は待機せずエラーを表示します。確認時点の一覧であり、実行時には再判定します。定時の自動削除は従来どおり動作します。
- ジョブ完了時はトーストで結果が通知されます。
- 待機失敗・ジョブ中断時は、失敗日時と理由を保存して再起動後も表示します。前回完了した実行結果とは区別し、次のジョブ完了で解除します。コピー／削除などの部分失敗もエラーとして表示します。

### 4. トレイ

ウィンドウを閉じてもアプリは常駐します。タスクトレイのアイコンから:

- 左クリック: 設定画面を表示
- 右クリック: メニュー（設定を開く / 今すぐ実行 / 終了）

完全に終了したい場合はトレイメニューの「終了」を使ってください。

### 5. ログ

「ログ」タブで `backup.log` の直近 500 行を新しい順に表示。情報 / 警告 / エラーでフィルタできます。詳細を読みたい場合は設定タブの「設定フォルダを開く」からエクスプローラで `logs/backup.log` を開けます。

## 開発

```bash
# 開発サーバ（ホットリロード）
npm run tauri dev

# Rust 単体テスト
cd src-tauri
cargo test --lib

# Lint
cargo clippy --all-targets -- -D warnings

# フロントエンド型チェック
npm run check
```

詳細な設計は [`DESIGN.md`](./DESIGN.md) を参照。

### 追加の回帰テスト

```bash
npm run test:unit
npm run test:ui
```

画面テストは Playwright とインストール済み Chrome が必要です。Playwright がプロジェクト外にある場合は `PLAYWRIGHT_MODULE` にその `index.mjs` の file URL を指定できます。IPC はすべてモック化し、実データ・自動起動設定には触れません。詳細な監査範囲・修正一覧・未検証事項は [`AUDIT.md`](./AUDIT.md) を参照してください。

設定ファイルが破損した場合は正常な `config.json.bak` から読み込みます。どちらも復旧できない場合は実行を停止してエラー表示します。設定画面の「設定フォルダを開く」から確認でき、壊れたファイルを黙って初期化することはありません。
